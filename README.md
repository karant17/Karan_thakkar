# Karan Thakkar - HR Technology Portfolio

Welcome to the source code for my professional portfolio. 
Built with modern web technologies: React, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Features
- Interactive Horizontal Experience Timeline
- Floating UI elements with Framer Motion animations
- Fully responsive design (Tailwind)
- Single Page Application (SPA) Routing with HashRouter for GitHub Pages compatibility

## 💻 Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## 🌐 Deployment
This project is configured to deploy easily to GitHub Pages.

1. Ensure the `homepage` URL or `base` in `vite.config.ts` is set up properly.
2. Run the deployment script:
   ```bash
   npm run deploy
   ```
